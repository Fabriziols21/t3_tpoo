# Bodexa - T1 Grupo 09

Este directorio contiene un prototipo didactico inicial de Bodexa preparado a partir del alcance del proyecto final del grupo. No es evidencia de que estas fuentes existieran en las semanas 1-5.

Requisitos: Java 17 o superior.

Compilar y ejecutar desde este directorio:

    javac -encoding UTF-8 -d out src/bodexa/*.java
    java -cp out bodexa.Main

Funciones: registrar productos, listar, buscar, vender un producto y avisar cuando el stock es inferior a cinco. Clases Producto, Venta y Main; ArrayList, metodos sobrecargados y excepciones.

Repositorio del proyecto final del companero: https://github.com/Soldier2006/Tecnicas-de-Program_G9
